# 🚲 Rueda Libre - Movilidad Sostenible en Medellín

Bienvenido al repositorio oficial del proyecto **Rueda Libre**, una plataforma web diseñada para ofrecer servicios de alquiler de bicicletas, recorridos guiados y taller de reparaciones en la ciudad de Medellín.

---

## 📋 Descripción del Proyecto

Este sitio web institucional y transaccional ha sido maquetado con **HTML5 semántico** y estilizado mediante **CSS3 puro** (Flexbox y CSS Grid), cumpliendo con los estándares de diseño adaptable (*Responsive Web Design*) y accesibilidad web.

### 🎨 Identidad Visual (Paleta Riwi)
* **Verde Ruta (`#1E7A4F`)**: Color primario para botones, llamados a la acción y elementos clave.
* **Naranja Pedal (`#F39A2B`)**: Color secundario para estados hover, alertas y detalles destacados.
* **Azul Noche (`#14213D`)**: Color institucional para encabezados, pie de página y tipografía principal.
* **Crema (`#FAF6EF`)**: Fondo general cálido.
* **Gris Asfalto (`#5B6470`)**: Tipografía de lectura y bordes sutiles.
